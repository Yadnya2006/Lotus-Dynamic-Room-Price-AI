# 🌿 Lotus Holiday Resort

## AI Dynamic Room Price Recommendation System

An AI-powered web application that predicts room prices for **Lotus Holiday Resort, Diveagar** using Machine Learning. The system recommends dynamic room prices based on room type, day type, season, number of guests, and extra guests.

---

# 📌 Features

- 🤖 AI-based Room Price Prediction
- 🏨 Supports Multiple Room Types
- 📅 Weekday & Weekend Pricing
- 🌞 Seasonal Pricing
- 👨‍👩‍👧 Guest & Extra Guest Pricing
- 📊 Python Generated Analytics Graphs
- 📋 Booking Summary
- 💡 AI Recommendation
- 🌐 Responsive Web Interface

# 🚀 Installation

Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

Open the project

```bash
cd Lotus_AI_Dynamic_Room_Price_System
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
